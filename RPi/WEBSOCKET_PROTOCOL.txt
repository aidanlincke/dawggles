Dawggles WebSocket protocol (port 8765)
========================================

Transport
---------
- Pi -> phone: JSON in TEXT frames; live preview as BINARY frames (raw JPEG bytes, one frame per message).
- Phone -> Pi: JSON in TEXT frames only.

A. Phone -> Pi: translation result (after scan / OCR)
------------------------------------------------------
Applied only while the Pi translation app is in a **live** session (JPEG stream running after capture).

{
  "app": "translation",
  "data": "<full summary string, optional but used for OLED fallback>",
  "groupings": [
    {
      "id": 0,
      "translated_text": "<string to show on OLED for this ROI>",
      "x": 0.0,
      "y": 0.0,
      "w": 0.0,
      "h": 0.0
    }
  ]
}

- x,y,w,h: normalized rectangle in Vision space (origin bottom-left), each in [0,1].
- Pi caches groupings; active line is `groupings[active_idx]`.

B. Phone -> Pi: active line (which ROI is under the reticle)
-------------------------------------------------------------
Sent only when the index changes (after alignment + hysteresis on the phone).

{
  "app": "translation",
  "event": "focus",
  "active_idx": 2
}

C. Pi -> phone: picture (existing)
----------------------------------
JSON with event "picture", image_b64, etc.

D. Pi -> phone: live JPEG stream
--------------------------------
Binary WebSocket message: JPEG bytes only (no multipart wrapper).

E. Pi -> phone: live stream ended
---------------------------------
{
  "app": "translation",
  "event": "preview_stopped"
}

Pi stopped sending live JPEGs (user ended session, disconnect cleanup, etc.). Phone should drop
live preview UI and stop alignment.
